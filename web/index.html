    BRING YOUR OWN SPARK

    连接你的 sparkDash

    需要 Python 3.11+、GitHub CLI 和你的 GitHub 账户。在能访问 sparkDash 的电脑或服务器上运行；保持上报器在线。

    1. 填写本地连接信息

      这些输入只在当前页面生成命令，不会发送给平台。地址不会写进公开报告。

    2. 在本机终端运行

      登录 GitHub 后按顺序执行。若 sparkDash 需要访问令牌，先运行 python3 -m arena.client token，在隐藏输入中填写。

      填写昵称和地址后生成加入命令。

      执行加入命令后，将公开昵称、GitHub 身份、每日模型及 Token 汇总；这是实例总用量，公开 Issue 历史可能保留。地址和令牌留在本机。公开与退出说明 ↗

    如何退出 / 什么会被统计？

    关闭自己的报名 Issue，或在本机运行 python3 -m arena.client leave，下次重建会移除你的所有榜单记录。公开 Issue 历史仍可能存在。

    平台汇总 Mia 的 sparkDash 小时历史。监控中断、重启和保留期可能导致缺失，因此只表示 sparkDash 实际记录到的用量，并非账单或硬件性能。多人共用实例时，昵称代表实例所有者，不代表个人消耗。
